# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of **Production RAG** seriously. If you discover a security vulnerability, please do **NOT** report it in a public GitHub issue.

Instead, please send an email to:
`security@doumein.com` (or create a private GitHub Security Advisory).

Please include:
1. Type of vulnerability (e.g. prompt injection, SQL injection, bypass of RBAC, rate-limiting bypass).
2. Step-by-step instructions to reproduce the issue.
3. Proof-of-concept payload or code snippet.
4. Potential impact.

### Response Timelines

- **Initial Acknowledgment**: Within 48 hours.
- **Triage & Status Assessment**: Within 5 business days.
- **Fix & Public Advisory**: Coordinated release within 30 days of validation.
